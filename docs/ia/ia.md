# Registro de uso de IA (ruta histórica)

Este archivo se conserva para no romper enlaces antiguos. La versión canónica, con las filas de
S1 a S14, está en **[`docs/ia.md`](../ia.md)**.

Cada fila del registro incluye para qué se usó la herramienta, qué se aceptó, **qué se rechazó y
por qué**, el resultado y el estado de revisión humana. Las filas de S10 a S14 están marcadas como
«Pendiente de revisión del equipo» hasta que sus integrantes las revisen en la sustentación.
